# Promise Unlocked Backend

Node.js 22 + TypeScript + Express + Firebase backend. Deployed as a Cloud Function.

## Quick Start

```bash
cd backend
npm install
cp .env.example .env
# Edit .env with your credentials
npm run dev
```

Server starts at `http://localhost:4000`. Swagger docs at `/api-docs`.
